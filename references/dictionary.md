# STE100 Dictionary Reference (Part 2)

## Dictionary Structure (4 Columns)

| Word (part of speech) | Approved meaning/ALTERNATIVES | APPROVED EXAMPLE | Not approved example |
|---|---|---|---|

- **Column 1**: Word in **bold**, **UPPERCASE** = approved, **lowercase** = unapproved. Part of speech in parentheses.
- **Column 2**: For approved words: the approved meaning. For unapproved words: suggested approved alternatives in UPPERCASE.
- **Column 3**: How to use the approved word/alternative correctly.
- **Column 4**: For unapproved words: example of incorrect usage. Empty for most approved words.

## Parts of Speech

1. **noun (n)** — person, place, object, idea, quality, or activity
2. **verb (v)** — state of being or action (with approved tenses)
3. **adjective (adj)** — modifies a noun/noun phrase
4. **adverb (adv)** — modifies verb, adjective, or another adverb
5. **pronoun (pron)** — replaces a noun or noun phrase
6. **article (art)** — indefinite (a, an) or definite (the)
7. **preposition (prep)** — shows relationship between parts of sentence
8. **conjunction (conj)** — connects words, phrases, and clauses

## Word Forms

- **Nouns**: singular form given; plural permitted unless help says otherwise
- **Verbs**: listed as: VERB (v), VERBS, VERBED, VERBED (infinitive/imperative, present, past, past participle)
- **Adjectives**: basic form with comparative/superlative in parentheses where applicable
- **Adverbs**: "-ly" form where applicable; "more"/"most" for comparative/superlative

## Key Dictionary Examples

### Approved word (noun):
| **ACCURACY (n)** | PRECISION (n) | THE PRECISION OF THE ADJUSTMENT CAN CHANGE. | The accuracy of the adjustment can vary. |

### Approved word (verb with forms):
| **ADAPT (v), ADAPTS, ADAPTED, ADAPTED** | To change or adjust to that which is necessary | ADAPT THE PRESSURE CONNECTION TO THE PITOT HEAD. | |

### Unapproved word with alternatives:
| **maintain (v)** | KEEP (v) | KEEP THE FLUID TEMPERATURE AT 70 °F. | Maintain the fluid temperature at 70 °F. |
| | HOLD (v) | TURN THE ROTATING TUBE 75 DEGREES. THEN HOLD THE TUBE IN THIS POSITION. | Turn the rotating tube 75 degrees. Then maintain the tube in this position. |
| | MAINTENANCE (n) | DO MAINTENANCE ON THE FUEL SYSTEM. | Maintain the fuel system. |

### Help (special usage notes):
Some entries include a "help" section that provides guidance on correct usage, restrictions, or context-specific alternatives.

## Flow Chart for Word Selection

1. Is the word an approved word in the dictionary? → Use it as approved
2. Is it an unapproved word? → Find the approved alternative in Column 2
3. Can it be a technical name? → Check Rule 1.5 categories
4. Can it be a technical verb? → Check Rule 1.12 categories
5. Otherwise → Find the best synonym from the approved dictionary

## Common Word Replacements

| Non-STE → STE Word | Non-STE → STE Alternative |
|--------------------|---------------------------|
| about (concerning) → approximately, around | have to → must |
| abandon → stop, go | insert → put |
| ability → can (v) | main → primary |
| able → can (v) | maintain → keep, hold, maintenance |
| abnormal → unusual, incorrect | may → can |
| ensure → make sure | now → at this time |
| follow → obey | perform → do |
| further → more | repeat → do again |
| rotate → turn | shall → must |
| should → must | test (v) → test (n) - "do a test" |
| therefore → thus, as a result | since → because |
| utilize → use | commence → start |
| approximately → about | initiate → start |
| sufficient → enough | require → necessary |
| prior to → before | subsequently → then |
| demonstrate → show | verify → check, make sure |
