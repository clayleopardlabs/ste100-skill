# STE Section 5: Procedural Writing (Rules 5.1–5.5)

| Rule | Summary |
|------|---------|
| **5.1** | Write instructions as direct commands (imperative mood): "Remove the screw." "Do the test." |
| **5.2** | Give one instruction per step. Each step must be a single, complete action |
| **5.3** | Put conditions before the action: "If the pressure is too low, fill the reservoir." |
| **5.4** | Use warnings and cautions before the step they apply to |
| **5.5** | Use notes to give explanatory information, not instructions or safety information |

## Deep Dive

**Rule 5.1 — imperative mood:** Start every step with a command verb (an approved word or a technical verb). If you cannot start with a command verb, the sentence is probably not a step.

- OK: "Remove the screw." / "Set the switch to OFF." / "Do the test."
- Violation: "The screw must be removed." / "You should check the pressure."

**Rule 5.2 — one instruction per step:** "Open the cover and remove the filter." -> two steps. Split them. Each bullet or step number holds exactly one action.

**Rule 5.3 — condition before action:** State the condition first, then the action, in the same sentence:

- "If the pressure is too low, fill the reservoir."
- "When the light comes on, set the switch to OFF."

Do not write the action first: "Fill the reservoir if the pressure is too low" is allowed but the condition-first order is preferred STE.

**Rule 5.4 — warnings before the step:** The WARNING/CAUTION immediately precedes the step it protects. Never bury a warning inside a step.

**Rule 5.5 — notes are not steps:** A note gives explanation ("The torque value is 5 N.m."). It is never a command. Do not format instructions as notes.

## List Structure

Procedures are written as vertical lists (Rule 4.3). Group steps into phases of at most 6 items:

```
Remove the old filter:
- Set the switch to OFF.
- Open the cover.
- Remove the filter.

Install the new filter:
- Install the new filter.
- Close the cover.
- Set the switch to ON.
```
