# STE100 Verb Tenses & Forms Reference

## Approved Verb Tenses

| Tense | Example | When to Use |
|-------|---------|-------------|
| **Infinitive** | (to) adjust | For expressing purpose or necessity |
| **Imperative (command)** | Adjust the linkage. | Primary form for procedural instructions |
| **Simple present** | The system operates correctly. | General truths, descriptions, conditions |
| **Simple past** | The operator adjusted the linkage. | Completed past actions |
| **Past participle (as adjective)** | The disconnected wires. The wires are disconnected. | Describing condition (NOT passive voice) |
| **Simple future** | The engine will operate. | Future actions, predictions |

## Unapproved Tenses (DO NOT USE)

| Tense | Example |
|-------|---------|
| **Present perfect** | has adjusted |
| **Past perfect** | had adjusted |
| **Present progressive** | is adjusting |
| **Past progressive** | was adjusting |
| **Present perfect progressive** | has been adjusting |
| **Passive voice** | is adjusted, was adjusted, will be adjusted |

## Active vs Passive Voice

**Active**: Subject does action → "The mechanic removes the panel."
**Passive**: Subject receives action → "The panel is removed by the mechanic."

**Test for passive**: Ask "by whom or by what?" If answerable, it's passive.

**Rule 3.6**: Use ONLY active voice in procedural writing. Use active as much as possible in descriptive writing.

## -ing Words

Only 7 approved -ing words exist:

| Word | Part of Speech |
|------|----------------|
| lighting | noun |
| opening | noun |
| routing | noun |
| servicing | noun |
| mating | adjective |
| missing | adjective |
| remaining | adjective |
| something | pronoun |
| during | preposition |

All other -ing forms are permitted only as:
- Technical names (e.g., "Cleaning Procedure")
- Modifiers in technical names (e.g., "grinding wheel", "welding torch")

## Sentence Length Limits

| Type | Max Words | Max Sentences per Paragraph |
|------|-----------|----------------------------|
| Procedural sentences | 20-25 | — |
| Descriptive sentences | 25-27 | 6 per paragraph |
| Vertical list items | 20 words, 2 sentences | 6 items per list |
| Noun clusters | 3 words (articles/prepositions don't count) | — |

## Safety Format

| Level | Meaning | Format |
|-------|---------|--------|
| **WARNING** | Risk of injury or death | WARNING: text → instruction |
| **CAUTION** | Risk of equipment damage | CAUTION: text → instruction |
| **Note** | Explanatory information only | Note: text |
